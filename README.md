# Game Idea Radar

Automated daily scouting of **trending US Google Play casual/puzzle games**. Every day at **8:00 AM IST** a cloud
Claude session (Sonnet 5.5) commits a report with **2 ideas**:

| | |
|---|---|
| **Idea A** | Exact clone of a proven hit (same mechanics and loop, new assets and theme) |
| **Idea B** | A proven mechanic plus one new twist |

Each idea has gameplay explanation, proof (installs, rating, chart rank, revenue **estimates**), Play Store screenshots, build estimate and risks.

## Read it
- Index: [`ideas/README.md`](ideas/README.md)
- Daily report: `ideas/YYYY-MM-DD/report.md`

## Talk to the bot
- Likes / dislikes → edit [`data/feedback.md`](data/feedback.md) (next run obeys it)
- Questions from the bot → [`data/questions.md`](data/questions.md), write your answer under the question

## How it avoids re-researching (saves tokens)
| File | Purpose |
|---|---|
| `data/ideas.json` | every idea ever delivered (no repeats) |
| `data/apps.json` | cache of researched apps (installs, rating, revenue band), refreshed after 30 days |
| `data/charts/DATE.json` | last 14 daily chart snapshots → detects NEW entries and risers |
| `data/candidates.json` | today's ranked shortlist, generated by script (0 LLM tokens) |
| `DAILY_RUN.md` | the run instructions (edit to change behaviour) |

## Data sources and honesty
Charts and app details come from Google Play (US). Revenue and download figures come from Sensor Tower's public
pages, which only give **bands** (for example "$1m-$10m"); the Top Grossing rank is the second signal.
These are estimates, not exact revenue.
